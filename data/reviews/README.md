# Curated reviews

One JSON file per SKU (`E95.json`, `H10.json`, …). **File order IS the ranking** — the fetcher takes index 0 as the review that ships on a `product_card_review` card.

Curation criteria — rank by: firsthand use > specific sensory/benefit detail > generic praise.

Exclude: gift/secondhand reviews ("it's for my son"), "haven't tried it yet", price-only praise, and any comparison to older Raycons.
